# Maintainer documentation

This tap distributes packages for projects maintained by FarisZR. Source
repositories build and publish release assets; this repository maintains the
Homebrew package definitions.

- [Release automation](automation.md): repository layout, source workflows,
  asset contracts, synchronization, and CI.
- [Tokens and permissions](tokens.md): credentials, secret locations, and rotation.
- [Maintenance](maintenance.md): manual synchronization, validation, adding
  projects, migration, and troubleshooting.

The root [README](../README.md) is the installation guide for users.
